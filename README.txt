## Teste
Abra `index.html` no navegador ou em um aplicativo/editor HTML.

Login de demonstração:
- Utilizador: `admin`
- Palavra-passe: `admin123`

## Importante
Esta versão usa `localStorage` para permitir testes sem servidor. Os materiais carregados e feedbacks ficam apenas no navegador/dispositivo usado no teste.

Para produção com link público, múltiplos administradores/dispositivos, autenticação realmente segura e armazenamento permanente de PDF/Word, deve-se ligar o frontend a um backend (por exemplo Firebase Authentication + Firestore + Storage). Não publique as credenciais de demonstração.
